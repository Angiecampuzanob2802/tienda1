# 🛒 Tienda1

Aplicación de escritorio desarrollada en **Java** que permite gestionar un inventario básico de productos.

El proyecto fue desarrollado como ejercicio práctico para fortalecer conocimientos en programación, manejo de productos y operaciones básicas sobre un inventario.

## 📌 Funcionalidades

La aplicación permite:

* ➕ Agregar productos al inventario.
* 📋 Mostrar los productos registrados.
* 🔎 Buscar productos.
* 📦 Consultar la información de los productos almacenados.

## 🛠️ Tecnologías utilizadas

* **Java**
* **Apache NetBeans**
* **Programación orientada a objetos**

## 🚀 Ejecución del proyecto

Para ejecutar el proyecto:

1. Clonar el repositorio.
2. Abrir **Apache NetBeans**.
3. Seleccionar **File → Open Project**.
4. Seleccionar la carpeta del proyecto `tienda1`.
5. Ejecutar el proyecto desde NetBeans.

## 📂 Estructura del proyecto

El proyecto contiene las clases y archivos necesarios para la gestión básica del inventario y las operaciones sobre los productos.

## 🎯 Objetivo

Desarrollar una aplicación sencilla para practicar conceptos fundamentales de programación en Java, como:

* Clases y objetos.
* Métodos.
* Atributos.
* Manejo de colecciones.
* Condicionales y ciclos.
* Gestión básica de información.
